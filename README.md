# Premium Theme-Switching Tetris Game 🎮

一個具備高質感視覺效果、行動版響應式設計（RWD）、以及主題自適應 Web Audio 聲音合成引擎的現代俄羅斯方塊網頁遊戲！只使用純 HTML5、CSS3 和 JavaScript 撰寫，完美支援瀏覽器直接點擊遊玩。

## 🌟 遊戲特色

### 1. 四大主題風格即時切換
- 🔮 **現代霓虹 (Modern)**: 賽博龐克紫色調、毛玻璃質感（Glassmorphism）、發光方塊與流暢的質感漸層。
- 📺 **傳統復古 (Retro)**: 經典 GameBoy 綠黃單色螢幕、懷舊掃描線（Scanline）特效、像素邊框方塊與 8-bit 電子合成音。
- 🌌 **浩瀚太空 (Space)**: 繁星閃爍背景、科技感準星方塊、電子網格介面與具備回音延遲（Echo Delay）的太空電子樂。
- 🌸 **浪漫粉櫻 (Romantic)**: 柔和的櫻花粉漸層、櫻花飄落動效、愛心印章方塊與浪漫音樂盒 chime 聲。

### 2. 純程式碼 Web Audio 合成音效與 BGM
- **零外部音檔加載**：完全不依賴外部 `.mp3`，不會有網路加載延遲或跨網域 CORS 問題，100% 由瀏覽器 CPU 即時合成音樂與音效。
- **動態編曲**：動態循環演奏經典俄羅斯方塊主題曲《Korobeiniki》並搭配低音 Bass。
- **音量控制**：內建靜音切換與無段式音量調整拉條。

### 3. 行動版 RWD 觸控手把
- **左手方向鍵**：大按鈕設計，包含保留鍵（Hold）。
- **右手旋轉鍵**：左旋轉、右旋轉實體手感排版。
- **DAS（延遲自動移動）**：長按左右或向下鍵會自動快速連發移動，操作手感流暢不卡頓。

### 4. 遊戲數據與高分紀錄
- **最高分儲存**：自動將您的最高分數（High Score）儲存在瀏覽器 `localStorage` 中。

---

## ⌨️ 鍵盤快捷鍵說明
- ◀ / ▶ 或 A / D : 左右移動
- ▼ 或 S : 軟降（加速下落）
- 空白鍵 (Space) : 硬降（瞬間下落）
- ▲ 或 X : 順時針旋轉
- Z : 逆時針旋轉
- C / Shift : 保留/更換方塊
- P / Esc : 暫停或繼續遊戲

---

## 🛠️ 開發架構
- 結構：`index.html`
- 樣式：`style.css`
- 邏輯：`app.js`
- 音效：`audio.js`

*只使用 Vanilla JS 與 Canvas API，無額外依賴框架。*
